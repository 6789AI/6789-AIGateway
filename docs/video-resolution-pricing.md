# 按次视频画质定价

在「模型定价 → 按次」中，先配置基础价格，再按需填写 **480p、720p、768p、1080p、2K** 的美元单价。空白画质沿用基础价格，`0` 表示该画质免费。删除模型定价或切换至 Token / 表达式模式会清除对应画质配置；批量复制包含画质价格。

现有「固定视频价格按时长计费」开关仍生效：关闭时，选定价格按一次任务收取；开启时，选定价格作为每秒价格乘以视频秒数。分组倍率、活动折扣及其他非分辨率倍率继续应用。活动固定价格替换选定画质的单价，活动折扣基于选定单价计算。界面会随开关显示每次 / 每秒单位。

配置存储于 `billing_setting.video_resolution_prices`，格式为模型名到画质价格对象的 JSON 映射。模型名使用客户端请求的公开名称，与基础 `ModelPrice` 一致；渠道映射后的上游名称用于选择模型及解析请求，不改变计费配置键。仅对已配置按次基础价格的视频任务生效，不影响 Token / 表达式价格或图片请求。

```json
{
  "对外模型名称": {
    "480p": 0.10,
    "720p": 0.20,
    "768p": 0.25,
    "1080p": 0.30,
    "2k": 0.40
  }
}
```

以上价格仅为格式示例。配置键使用 `2k`；请求侧大小写不敏感，`1440p` 也匹配 2K。未配置、无法识别的画质继续按原基础价格与原倍率计费。配置接口拒绝负数、空值、非数字及不支持的画质键。

支持读取 OpenAI / Sora（含 Vinted）、Ali、Gemini / Vertex Veo、Vidu、MiniMax Hailuo、DoubaoVideo 适配器实际使用的画质。Ali / Vidu / Hailuo / Doubao 使用转换后的参数，Veo 使用现有有效分辨率解析。Vinted 使用当前目录校验及默认值填充后的 `parameters.resolution`；目录未声明且被忽略的画质不参与定价。不支持该画质的模型仍会按既有上游校验拒绝请求，定价表不会新增模型能力。

命中画质单价时，替代内置 `size`、`resolution`、`resolution-*` 倍率，避免重复收费。Doubao 的复合倍率仅保留同画质下的视频输入折扣。最终单价、画质与倍率策略写入任务计费快照；之后改价不会改变在途任务的结算规则。日志包含 `video_resolution` 和 `resolution_price`，失败退款沿用原有扣费会话及任务退款链路。所有额度转换沿用安全额度计算及溢出审计。

普通 Sora remix 没有指定新画质时，继承原任务记录的画质；旧任务缺少画质快照时沿用基础价，不推断为新建任务的默认画质。Vinted 仍不支持 remix。

价格同步 API 与模型价格 API 均携带 `video_resolution_prices`；管理端可按模型同步，Token / 表达式模式切换会清理画质附加价格。无需数据库结构迁移。
